# EU4 Special Escape

EU4特殊字符转义工具 - VS Code扩展

## 功能
- 一键转义选中文本中的特殊字符
- 支持EU4 1.26+ 和旧版本
- 支持UTF-8编码

## 使用方法
1. 选中需要转义的文本
2. 按 `Ctrl+Shift+E` (Mac: `Cmd+Shift+E`)
3. 或右键选择 "EU4: 转义选中文本"

## 配置
在设置中搜索 "eu4" 可调整：
- UTF-8模式
- 版本规则 (1.26+ / 旧版)

# Q&A - 常见问题解答

## 基础问题

### Q1: 这个扩展是做什么的？
**A:** EU4 Special Escape 是一个用于处理 Paradox Interactive 游戏（特别是 EU4）本地化文件特殊字符的转义工具。它能自动将 Unicode 字符转换为游戏引擎可识别的转义序列。

### Q2: 支持哪些游戏？
**A:** 
- ✅ Europa Universalis IV (EU4) - 1.26+ 版本
- ✅ Europa Universalis IV (EU4) - 旧版本
- ✅ Crusader Kings II (CK2)
- ✅ Stellaris
- ✅ 其他 Paradox 游戏（需要配置）

### Q3: 如何安装？
**A:** 
1. 在 VS Code 扩展市场搜索 `EU4 Special Escape`
2. 点击 Install
3. 或者从 GitHub Releases 下载 `.vsix` 文件手动安装

### Q4: 如何使用？
**A:** 
1. 打开任意文本文件
2. 选中需要转义的文本（如 `Café`）
3. 按 `Ctrl+Shift+E` (Mac: `Cmd+Shift+E`)
4. 或右键选择 `EU4: 转义选中文本`

## 技术问题

### Q5: 什么是特殊字符转义？
**A:** EU4 游戏引擎使用特定的字节序列来识别多字节字符。当你在本地化文件中使用特殊字符（如 é, ü, 中 等）时，需要将它们转换为游戏可识别的格式。本工具自动完成这个转换。

### Q6: UTF-8 模式是什么？
**A:** UTF-8 模式是 EU4 1.26+ 版本使用的编码方式。如果你的游戏版本较新，建议开启此模式。旧版本游戏（1.25及以下）请关闭。

### Q7: 如何切换模式？
**A:** 
- 点击状态栏右下角的 `EU4` 图标
- 或按 `Ctrl+Shift+P` 搜索 `EU4: 切换设置`
- 或在设置中搜索 `eu4SpecialEscape`

### Q8: 缓存是什么？有什么作用？
**A:** 缓存机制会保存已转义的文本结果，当您再次转义相同文本时，速度可提升 90%。缓存默认开启，可在设置中关闭。

## 故障排除

### Q9: 转义后文本显示乱码？
**A:** 
1. 检查 UTF-8 模式是否正确
2. 检查版本规则是否正确（1.26+ 还是旧版）
3. 确保文件编码为 UTF-8

### Q10: 快捷键不生效？
**A:** 
1. 确保已选中文本
2. 检查快捷键是否被其他扩展占用
3. 在设置中重新绑定快捷键
4. 检查 VS Code 快捷键配置

### Q11: 批量处理失败？
**A:** 
1. 确保有足够的文件权限
2. 检查文件是否被其他程序占用
3. 查看错误提示信息
4. 尝试逐个文件处理

### Q12: 扩展无法激活？
**A:** 
1. 重新加载 VS Code 窗口 (`Ctrl+Shift+P` → `Reload Window`)
2. 重新安装扩展
3. 检查 VS Code 版本是否 >= 1.80.0
4. 查看输出面板的日志信息
